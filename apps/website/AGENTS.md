# Website agent guidance

The repository AGENTS.md applies. For HTML/CSS and client-side work, follow
[Modern Web Guidance](../../docs/modern-web-guidance.md) and read the relevant
installed Next.js documentation in `node_modules/next/dist/docs/` before changing
framework behavior. Use the shared project-local skill and root `pnpm mwg`
commands. MWG is development tooling, not a website runtime dependency.
